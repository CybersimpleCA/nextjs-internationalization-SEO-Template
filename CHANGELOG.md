# Changelog

All notable changes to this Next.js i18n template will be documented in this file.

## [1.0.0] - 2024-01-01

### Added
- Complete Next.js 15 setup with TypeScript
- Internationalization with next-intl v4.3.1
- Path-based routing (`/en`, `/es`)
- Automatic locale detection
- SEO-friendly metadata generation
- OpenGraph and Twitter Card support
- JSON-LD structured data
- Tailwind CSS integration
- Language switcher component
- Custom 404 page with translations
- Comprehensive .gitignore
- PostCSS and Autoprefixer configuration
- Development and production scripts

### Features
- ✅ Multi-language support (English, Spanish)
- ✅ SEO optimization
- ✅ Responsive design with Tailwind CSS
- ✅ TypeScript support
- ✅ Server-side rendering
- ✅ Static generation support
- ✅ Easy to extend with new languages

### Developer Experience
- Hot reload with Turbopack
- ESLint configuration
- TypeScript strict mode
- Component-based architecture
- Clear project structure
